把鼠标变成一只取景器

2026-11-18 20:30# 交互设计# CSS

用两层照片和一个圆形裁切，让指针经过的地方露出颜色。

取景框的中心跟着指针走，里面的颜色稍慢半拍。边框可以告诉手指现在指着哪里，后面的光则留一点重量。

从一个小圆开始

同一张森林照片叠放两次。底层显示黑白，上层保留彩色。用 CSS 的 clip-path 在上层裁出一个圆，取景框里就会露出原来的颜色。

.reveal {
  clip-path: circle(var(--rad) at var(--px) var(--py));
}

按住与松开

按住的时候，显影区域向外扩开。松开，眼睛重新落回一个局部。

  • 移动指针，可以比较相邻两棵树的颜色。
  • 按住画面，可以看到树冠四周的阴影。
  • 想认真看完整张照片，可以用封面右下角的「整幅显色」。
